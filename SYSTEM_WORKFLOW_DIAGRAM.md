## 执行模式详解

### 1. Simple模式 (单轮问答)

```
用户提问
    │
    ▼
┌─────────────────────────────────────┐
│  process_message() [agents.py]      │
│  ├─ route_to_agent() 关键词路由     │
│  │  ├─ "搜索"/"查找" → researcher  │
│  │  ├─ "代码"/"编程" → coder       │
│  │  ├─ "分析"/"对比" → analyst     │
│  │  └─ 其他 → general              │
│  └─ AGENT_FUNCS[agent_name]()       │
└─────────────────────────────────────┘
    │
    ├─→ Researcher: 搜索+RAG检索
    │     └─ search_web() + rag_retrieve()
    │
    ├─→ Coder: 代码生成+执行
    │     └─ chat_completion() + execute_code()
    │
    ├─→ Analyst: 分析推理
    │     └─ chat_completion()
    │
    └─→ General: 通用对话
          └─ chat_completion()
    │
    ▼
返回答案
```

---

### 2. ReAct模式 (推理+行动循环)

```
用户任务
    │
    ▼
┌─────────────────────────────────────────────────┐
│  ReactAgent.run() [react_agent.py]              │
│                                                  │
│  循环 (最多10次):                                │
│  ┌───────────────────────────────────────────┐  │
│  │  1. LLM思考 (Thought)                     │  │
│  │     "我需要先搜索最新信息..."               │  │
│  │                                            │  │
│  │  2. 选择行动 (Action)                      │  │
│  │     {"tool": "web_search",                │  │
│  │      "parameters": {"query": "..."}}      │  │
│  │                                            │  │
│  │  3. 执行工具 (Observation)                 │  │
│  │     ToolRegistry.execute("web_search")    │  │
│  │     └─→ 返回搜索结果                        │  │
│  │                                            │  │
│  │  4. 判断是否完成                            │  │
│  │     完成 → 输出 Final Answer              │  │
│  │     未完成 → 继续循环                       │  │
│  └───────────────────────────────────────────┘  │
└─────────────────────────────────────────────────┘
    │
    ▼
返回答案 + 工具调用记录
```

## 关键机制说明

### 1. 自动模式选择

```python
# autonomous.py: _detect_complexity()

任务文本
    │
    ├── 包含 "深入研究"/"全面分析"/"多角度" → Multi模式
    │
    ├── 包含 "分析"/"比较"/"搜索"/"编写"/"计算" → ReAct模式
    │
    └── 其他 → Simple模式
```

### 2. ReAct循环示例

```
用户: "帮我搜索最新的AI新闻并总结"

Iteration 1:
  Thought: 需要先搜索AI新闻
  Action: {"tool": "web_search", "parameters": {"query": "AI news latest"}}
  Observation: [搜索结果列表...]

Iteration 2:
  Thought: 已获取结果，需要总结
  Final Answer: 根据搜索结果，最新AI新闻包括...
```

### 3. 自我反思机制

```
答案生成后
    │
    ▼
SelfReflection.should_retry()
    │
    ├─ 评估维度:
    │  ├─ 完整性 (是否回答了问题)
    │  ├─ 准确性 (信息是否可靠)
    │  ├─ 可执行性 (代码是否可运行)
    │  └─ 清晰度 (表达是否清楚)
    │
    ├─ 评分: 0-10
    │
    └─ 决策:
       ├─ 分数 >= 7 → 通过
       └─ 分数 < 7 → 标记需改进
```

## 总结

这个Agent系统采用**分层架构**：

1. **表现层** (main.py) - Streamlit UI
2. **控制层** (autonomous.py) - 模式选择、流程编排
3. **执行层** (agents/) - 多种执行策略
4. **能力层** (tools/, rag/) - 工具、知识库
5. **基础层** (llm_client, memory) - LLM调用、记忆管理

**核心特性**：
- 自动模式选择（Simple/ReAct/Multi）
- 工具动态注册与调用
- RAG知识增强
- 自我反思与学习
- 多轮记忆压缩
- 完整统计追踪
